### What is Crewloom?

Crewloom is an open-source toolkit for structured AI agent work. Give an agent a specialist role, project context and working memory, then verify its output with practical tools. Connect remote agent operations through the companion bridge.

Use your existing agent host and model. Keep project context, review and execution evidence close to the work.
